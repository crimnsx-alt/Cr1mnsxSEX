# Инструкция по подключению Supabase к Cr1mnsx PS5 System Shell

Система друзей в проекте поддерживает полноценный облачный backend на базе **Supabase** (PostgreSQL + RLS + REST API) с автоматическим переключением на надежный локальный режим (`localStorage`), если ключи еще не указаны.

---

## Шаг 1. Создание проекта в Supabase
1. Перейдите на [https://supabase.com](https://supabase.com) и зарегистрируйтесь / войдите.
2. Нажмите **New Project**, укажите имя (например, `ps5-friends`) и сохраните пароль базы данных.
3. Дождитесь готовности базы данных (около 1–2 минут).

---

## Шаг 2. Применение структуры базы данных (SQL)
1. В панели управления Supabase перейдите в раздел **SQL Editor** (слева в меню).
2. Нажмите **New Query**.
3. Скопируйте всё содержимое файла [`supabase_schema.sql`](file:///Users/cr1mnsx/ps5ux/supabase_schema.sql) и вставьте в редактор.
4. Нажмите **Run**.
   - Будут созданы таблицы: `profiles`, `friend_requests`, `friendships`.
   - Включатся правила безопасности **Row Level Security (RLS)**, защищающие персональные данные.
   - Будет сконфигурирован публичный бакет для аватаров `avatars`.

---

## Шаг 3. Копирование ключей в проект
1. В панели Supabase перейдите в **Project Settings** → **API**.
2. Скопируйте:
   - **Project URL** (вида `https://abcdefghijklm.supabase.co`)
   - **anon / public** key (длинный JWT-токен под надписью `Project API keys` / `anon public`)
3. Откройте файл [`js/supabase-config.js`](file:///Users/cr1mnsx/ps5ux/js/supabase-config.js) и укажите ваши значения:

```javascript
export const SUPABASE_CONFIG = {
  url: "https://ВАШ-ПРОЕКТ.supabase.co",
  anonKey: "ВАШ-АН-ОН-КЛЮЧ-ИЗ-SUPABASE",
  adminPin: "1994", // ПИН-код владельца для одобрения/отклонения заявок
  storageBucket: "avatars"
};
```

---

## Шаг 4. Управление заявками (Режим владельца)
- В блоке «Друзья» нажмите **«Заявки»**.
- Перейдите на вкладку **«Управление (Владелец)»**.
- Введите ваш ПИН-код (по умолчанию `1994`, настраивается в `supabase-config.js`).
- Вы увидите все поступившие заявки, сможете просмотреть профили (Steam, TG, VK, Discord, PSN) и нажать **[Принять]** или **[Отклонить]**.
- После нажатия «Принять» друг мгновенно появляется в подтвержденном списке друзей на главном экране Welcome Hub!
