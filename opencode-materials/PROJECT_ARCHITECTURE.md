## 2. Структура проекта

```
/
├── index.html                   # Главный HTML-документ (Welcome Hub, оверлеи, модалки)
├── css/
│   └── style.css                # Полная дизайн-система PS5 + Framer/Apple анимации (7500+ строк)
├── js/
│   ├── app.js                   # Основной контроллер интерфейса, навигация, биндинги

│   ├── sound.js                 # Аудиодвижок PS5 (Web Audio API, эмбиент-синтезатор, каналы)

│   ├── friends-service.js       # Система друзей, запросов и профилей контактов
│   ├── icons.js                 # SVG-иконки геймпада DualSense, трофеев, системных пиктограмм
│   ├── particles.js             # 5D Canvas частицы PS5 (волны, боке, световые нити)
│   ├── supabase-config.js       # Конфигурация Supabase для мультиплеера/друзей
│   └── qrcode.min.js            # Генератор QR-кодов для донатов / мобильного подключения
├── data/
│   └── psn-trophies.json        # Кэш реальных трофеев PSN пользователя Cr1mnsx
├── assets/
│   ├── audio/ps5/
│   │   ├── active/              # 26 проверенных WAV-файлов системы PS5
│   │   ├── reserved/            # 4 зарезервированных WAV-файла (party, checkout, logout)
│   │   ├── manifest.json        # Полный JSON-манифест всех 45 звуков
│   │   └── README.md            # Документация аудиосистемы
│   ├── covers/                  # Обложки игр (GTA VC, GTA V, DOOM, NFS U2, Simpsons и др.)
│   └── wallpapers/              # 4K-обои для динамического фона игр
├── scripts/
│   ├── server.js                # Dual-stack IPv4/IPv6 статический HTTP сервер (порт 8080)
│   ├── sync-psn-trophies.mjs    # Node.js скрипт синхронизации с PSN API
│   └── psn-trophy-sync.workflow.yml # Шаблон GitHub Actions для автообновления трофеев
└── opencode-materials/          # Пакет для Open Code со всеми скиллами и инструкциями
```

## 3. Ключевые возможности проекта
1. **Welcome Hub 1:1 PS5 System Software:**
   - Горизонтальная лента переключения игр с активным масштабированием и 3D-перспективой.
   - Bento-сетка виджетов: Друзья онлайн, Специальные возможности, Коллекция призов, Память консоли (M.2 NVMe), Аккумуляторы DualSense / PULSE 3D, PlayStation Store.
   - Двухуровневая вертикальная навигация: скролл вниз открывает Game Hub с карточками активностей.
2. **PSN Trophy Sync:**
   - Отображение реального профиля `Cr1mnsx` (1 842 трофея, Уровень 284, Платина 24, Золото 148, Серебро 462, Бронза 1208).
   - Полноэкранный просмотр коллекции с фильтрами и карточками достижений.
3. **PS5 System Sound Library:**
   - 26 активных оригинальных звуков PS5, привязанных ко всем действиям UI.
   - Центр тестирования звуков в Настройках.
4. **Стандарт анимаций elite-ui-master:**
   - Aceternity Spotlight курсор на карточках.
   - NumberFlow счетчики с одометр-эффектом.
   - Пружинный отклик на кнопках.
   - Световой блик на кубках трофеев.
