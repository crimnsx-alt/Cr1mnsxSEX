# PlayStation Network (PSN) Trophy Sync Architecture

## 1. Концепция и цель
- Автоматическая и ручная синхронизация настоящих трофеев пользователя (`Cr1mnsx`) с PlayStation Network.
- Отображение: аватар, онлайн-статус, уровень трофеев, процент до следующего уровня, Platinum/Gold/Silver/Bronze кубки, список всех игр с процентом завершения, датами получения трофеев.

## 2. Безопасность и архитектура GitHub Pages
- **Статический хостинг (GitHub Pages):** Не может хранить приватные секреты PSN (токен `npsso` и OAuth-ключи) на клиентской стороне!
- **Правило безопасности:** Токены PSN ЗАПРЕЩЕНО сохранять в публичном репозитории, HTML, клиентском JS или `localStorage`.
- **Архитектура синхронизации:**
  1. **Tier 1 (GitHub Actions Cron / Dispatch):**
     - Скрипт `scripts/sync-psn-trophies.mjs` запускается в GitHub Actions (секрет `PSN_NPSSO`).
     - Использует официальную/полуофициальную библиотеку `psn-api`.
     - Генерирует кэшированный JSON: `data/psn-trophies.json`.
     - Рабочий процесс описан в `scripts/psn-trophy-sync.workflow.yml`.
  2. **Tier 2 (Клиентский PSN Service):**
     - Модуль `js/psn-service.js` загружает `data/psn-trophies.json` с проверкой кэша.
     - Поддерживает ручную кнопку **Sync Now** и резервный импорт пользовательского JSON (модальное окно `modalPsnJsonImport`).
     - Гидрирует карточку трофеев в Welcome Hub и полноэкранное модальное окно коллекции трофеев (`modalTrophyCollection`).

## 3. UI-компоненты трофеев
- **Виджет в Welcome Hub:** Кубки (Platinum, Gold, Silver, Bronze), общий счетчик, уровень и анимированная полоса прогресса.
- **Полноэкранное окно коллекции трофеев (`#modalTrophyCollection`):**
  - Шапка с профилем игрока и статистикой.
  - Поиск по играм и фильтры: *Все игры, С платиной, 100% пройдено, В процессе, Не начатые*.
  - Bento-сетка игр с постерами, датами и шкалой прогресса.
  - Окно детального просмотра трофеев отдельной игры (`#modalGameTrophiesDetail`).
