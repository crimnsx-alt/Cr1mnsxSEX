# Anti-Slop Guidelines (Запрет на шаблонную генерацию)

## 1. Запрещенные визуальные штампы (UI AI-Slop)
- **Никаких дефолтных фиолетово-розовых и неоново-синих градиентов** (`linear-gradient(to right, #6366f1, #a855f7)`), выдающих дешевый AI-лендинг.
- **Никаких эмодзи вместо иконок** (🚀, ✨, 💡, 🔥, 🏆). Используй исключительно чистые векторные SVG-иконки с единой толщиной линии (`stroke-width: 1.75` или `2`).
- **Никаких одинаковых скучных карточек** с центрированным текстом и тенью по умолчанию. Используй асимметричную Bento-сетку, точную иерархию размеров и настоящие системные референсы (например, оригинальные гайдлайны Sony PS5 UI).
- **Никаких пустых декоративных заглушек:** каждый элемент интерфейса (прогресс-бар, переключатель, кнопка, бейдж) обязан нести реальную функцию и иметь рабочие состояния `:hover`, `:focus-visible` и `:active`.

## 2. Типографика и Сетка
- Четкий контраст размеров: крупные, плотные заголовки (`letter-spacing: -0.03em`, `font-weight: 700–800`) и спокойный, легко читаемый вторичный текст (`rgba(255, 255, 255, 0.65)`).
- Стеклянные поверхности (`glassmorphism`) всегда должны иметь тонкую полупрозрачную рамку (`1px solid rgba(255, 255, 255, 0.14)`) и глубокое размытие (`backdrop-filter: blur(20px)`), чтобы текст не сливался с фоном.

## 3. Запрет на слоп в текстах (Copywriting)
- Запрещены клише: «Добро пожаловать в мир...», «Инновационный», «Выведите на новый уровень», «Погрузитесь в уникальную атмосферу», «Современные решения».
- Пиши коротко, конкретно и в стилистике нативного интерфейса ОС/консоли: вместо «Узнайте больше о моих уникальных проектах» — «Проекты (4)», «Запустить», «Сборка v2.4».

## 4. Чистота кода
- Никаких обрезанных кусков вида `// ... остальной код без изменений ...` — всегда выдавай полный рабочий модуль.
- Используй CSS-переменные (`:root`), плавные физические кривые анимации (`cubic-bezier(0.22, 1, 0.36, 1)`) вместо линейных `ease-in-out` и полную поддержку навигации с клавиатуры.
