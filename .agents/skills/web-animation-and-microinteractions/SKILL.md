# Web Animation & Micro-interactions Guidelines

## 1. Физика движения и кривые скорости
- **Запрет на дефолтный `ease-in-out`**: Используй фирменные кривые с быстрым откликом и естественным торможением:
  - Пружинистый отклик интерфейса (Snappy): `cubic-bezier(0.2, 0.9, 0.3, 1)` (PS5 Flow / Apple Spring).
  - Плавное выкатывание оверлеев/модалок: `cubic-bezier(0.16, 1, 0.3, 1)`.
  - Затухание/закрытие: `cubic-bezier(0.4, 0, 0.2, 1)`.
- **Длительность (Timing)**:
  - Микро-реакции (кнопки, иконки, тултипы): `120ms – 200ms`.
  - Карточки, фокус, выпадающие списки: `240ms – 320ms`.
  - Модальные окна, оверлеи на весь экран: `350ms – 450ms`.

## 2. Аппаратное ускорение (GPU Acceleration)
- Анимируй **только дешевые свойства**: `transform` и `opacity`.
- Никогда не анимируй свойства, вызывающие reflow/layout: `top`, `left`, `width`, `height`, `margin`, `padding`.
- Используй `will-change: transform, opacity;` на активно анимируемых слоях с последующим сбросом.

## 3. Микро-взаимодействия (States & Feedback)
- **Hover**: Приподнимание элемента (`transform: translateY(-3px)`), масштабирование (`scale(1.02)`), усиление глубины тени и мягкий ореол.
- **Active / Press**: Мгновенный тактильный отклик при клике (`transform: scale(0.97)`).
- **Focus-Visible**: Контрастный контур для доступности с клавиатуры (`outline` или светящийся `box-shadow`).

## 4. Доступность (A11y)
- Обязательная поддержка `@media (prefers-reduced-motion: reduce)`: мгновенная смена состояний без анимации движения для пользователей с вестибулярной чувствительностью.
